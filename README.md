## SaaS Dashboard

A modern SaaS-style dashboard built with Next.js, React, and TypeScript.

This project demonstrates real-world frontend patterns including:
- Server state management with React Query
- Client-side state with Zustand
- Form handling and validation with React Hook Form + Zod
- Data visualization using Recharts
- Responsive UI built with Tailwind CSS and shadcn/ui
- Interactive data tables with filtering, sorting, editing, and actions

Designed to reflect production-level frontend architecture and user experience.
